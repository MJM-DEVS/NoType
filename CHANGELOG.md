# Changelog

All notable changes to NoType are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow the `version` field in `electron/package.json`.

This file was written after the fact from the commit history. Dates are those of the release tag where one exists, otherwise of the version bump commit. Versions before 2.4.0 are not listed; see `git log`.

## [Unreleased]

### Added
- `CHANGELOG.md`, `SECURITY.md`, `CONTRIBUTING.md`, `RELEASING.md`, issue and pull request templates.
- `docs/configuration.md`, a reference of every settings key, generated by `tools/gen_config_docs.py` (with `--check`) and covered by a test.
- `requirements-build.txt` for PyInstaller and the bundled cuBLAS.
- The setup guide asks whether NoType may check for updates. On the first run the first automatic check waits until the guide is done.
- README: a table of every connection NoType makes, when, to where and how to avoid it.

### Fixed
- PCs without an NVIDIA card load the speech model again. The settings window saved `float16` as the quantization for everyone, and the processor can't run it; it now offers Auto (the default) and the processor uses int8. A load that fails tries the other compute types of the device before giving up, and a slow load on the processor is no longer cut off while it still makes progress.
- A model that could not be loaded no longer shows "loading" forever: the tray, the settings, the setup guide and the hotkey say that it failed, why, and what to do. "Try again" in the toast, the tray menu, the settings and the setup guide loads it once more (saving the settings still does too). A backend that keeps crashing is shown the same way instead of "loading".
- A backend that can't start (a missing DLL, say) is no longer restarted forever while the tray says "loading". The circuit breaker counted exits less than 10 s apart, and its own 16 s back-off reset that count before it reached five; it now counts backends that die within 10 s of their start, gives up after five (about 30 s) and shows "Try again".
- A load ends in "ready" or "failed" whatever goes wrong in between, also on an unexpected error in the speech engine or when saving the compute type fallback fails.
- A processor without AVX and a missing or blocked part of the install (DLL, module) get their own message instead of "pick a smaller model".
- The first download of a model shows how far it got in the setup guide, and a download that still makes progress is no longer cut off after an hour.
- When the model doesn't fit into the graphics memory, the fallback toast says so instead of "graphics card is not responding".
- A `settings.json` edited by hand on Windows is read in the encoding it was saved in: with a BOM (Notepad), as UTF-16 (PowerShell's `>`) or in the ANSI code page (`Set-Content`). Before, the backend crashed at every start on the last two, and on a BOM it fell back to an older backup and wrote it over the edit. Saving waits briefly for a `settings.json` that a virus scanner or a sync client holds open, and a file that stays locked is no longer replaced by a backup.
- A dictation is no longer lost when saving the compute type fallback fails (locked `settings.json`).
- A model download that fails because a virus scanner still holds a just-downloaded file is tried again (twice) instead of ending as "download failed".
- A backend that can't start says why: missing or blocked `backend.exe` or DLL ("reinstall"), a processor without AVX, or the generic message. Giving up always shows a toast now; before, the toast of the first crash ("restarting …") was the last one. Import errors at the start are written to `notype.log` (home folder as `~`), and the backend and the speech engine process end with exit code 1 instead of an unhandled exception, which the windowed build shows as a modal dialog after every restart.
- The voice activity detection (Silero VAD, onnxruntime) loads together with the model. Before, an onnxruntime that could not load (a DLL removed by a virus scanner, an older VC++ runtime) let the model show "ready" and then failed every dictation without a reason; now the load fails with "a part of the speech engine is missing" and the log names the onnxruntime version or why it did not load.
- `notype.log` gets a short description of the machine at every start of the speech engine: OS, processor features (AVX/AVX2/AVX-512), memory, CTranslate2 and faster-whisper versions, CUDA devices and compute types, and why CUDA wasn't used. No host or user name, no paths; the home folder in error messages is written as `~`.

### Changed
- `requirements.txt` asks for `faster-whisper>=1.1` and no longer lists PyInstaller.
- README: the tagline, privacy badge and privacy bullet no longer say that nothing ever leaves the PC, and point to the list of what goes online. Developer notes, with a complete project structure, moved to `docs/development.md`.

## [3.3.1] - 2026-11-06

### Changed
- Whisper runs in its own process, watched and replaced by the backend, so a graphics driver reset no longer leaves NoType broken until a restart. A failed dictation is retried, on the processor if the card keeps failing, and the engine returns to the card by itself.

### Added
- While speaking, the recording also goes to disk and is deleted once the text is in. A recording that could not be transcribed stays for 7 days at most and can be transcribed again from the tray menu. Settings can switch this off (`rescue_audio`).

## [3.3.0] - 2026-10-28

### Added
- Spoken punctuation in German, English and Polish ("comma", "new line", "question mark" …).
- Shares per language under My languages; short sentences are weighed against the mix.
- A filter for phrases Whisper invents in silence ("Thanks for watching" and similar, ten languages).
- Long dictations on an NVIDIA card decode in parallel batches.

### Changed
- Dark gets its own look; Sage gets drawn icons. Settings and setup are opaque in both designs. The Quicksand font ships with the app.
- Errors name the cause and offer the next step as a button. Closing settings with unsaved changes asks first, and the hotkey field explains why a combination was rejected.

## [3.2.0] - 2026-10-12

### Added
- Agent hotkey (off by default): sends a dictation as JSON to a URL from the settings instead of typing it, with an optional Bearer token, and shows the reply in the overlay. Redirects are not followed. The request format is documented in the README.

## [3.1.0] - 2026-10-10

### Added
- Two designs, Dark and Sage, across every window, or Automatic to follow Windows.
- Line, a calm overlay style that exists in both designs.

## [3.0.0] - 2026-10-09

There is no `v3.0.0` tag in the repository; the version was bumped and followed by 3.1.0 the same day.

### Added
- Copies and screenshots made while dictating into an AI app, a terminal, a code editor or a browser go along with the sentence.
- <kbd>Esc</kbd> cancels a dictation.
- Optional: mute other audio while dictating.

### Changed
- The microphone is remembered by name instead of by index.
- Shortcuts in settings and setup are drawn as key caps.

## [2.9.0] - 2026-10-04

### Added
- One-click updates from GitHub releases for the installed version, with a switch to turn the automatic check off. The portable version links to the release page.

### Changed
- Uninstalling also removes the update cache.

## [2.8.0] - 2026-10-04

### Added
- Start with Windows toggle in settings, tray menu and setup.
- Slime, Dragon and Mimic overlay styles.

### Changed
- Downloaded speech models load from the local cache without asking the Hugging Face Hub.
- The log no longer holds dictated text; older logs that did are deleted once.
- The uninstaller removes `%APPDATA%\NoType` and the autostart entry.

## [2.7.0] - 2026-09-29

### Added
- Command mode: rewrite the selection (or write new text) by voice with the local LLM.
- Learned dictionary of corrections, with suggestions when a dictated word is fixed in place (UI Automation, never in password fields).
- Dot Matrix, Island, Halo and Buddy overlay styles, seven accent colors, live preview in settings.
- In-app update of the portable Ollama.

### Changed
- License changed to MIT with the Commons Clause.
- README rewritten for end users.

## [2.6.0] - 2026-09-05

### Added
- Overlay position (bottom, top, center) for every style; the overlay holds the inserted sentence for a moment.
- Model picker for AI cleanup.

### Fixed
- cuBLAS is bundled with the backend, so the GPU path no longer depends on a CUDA toolkit on `PATH`. The installer grows to about 1 GB.

## [2.5.0] - 2026-09-05

### Added
- Model cards with download size, VRAM need and a recommendation for the detected GPU.
- First-run setup guide with a test dictation.
- A processing state in the overlay after the key is released.

## [2.4.0] - 2026-09-05

### Changed
- Hold-to-speak stops on the real key release instead of a timer, which removes about 350 ms per dictation.
- Toasts follow the app language; settings polish.

### Fixed
- Settings were not saved while the backend was down or restarting.
