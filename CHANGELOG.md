# Changelog

All notable changes to NoType are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow the `version` field in `electron/package.json`.

This file was written after the fact from the commit history. Dates are those of the release tag where one exists, otherwise of the version bump commit. Versions before 2.4.0 are not listed; see `git log`.

## [Unreleased]

### Added
- `CHANGELOG.md`, `SECURITY.md`, `CONTRIBUTING.md`, `RELEASING.md`, issue and pull request templates.
- `docs/configuration.md`, a reference of every settings key, generated by `tools/gen_config_docs.py` (with `--check`) and covered by a test.
- `requirements-build.txt` for PyInstaller and the bundled cuBLAS.

### Changed
- `requirements.txt` asks for `faster-whisper>=1.1` and no longer lists PyInstaller.
- README: the tagline, privacy badge and privacy bullet no longer say that nothing ever leaves the PC, and point to the list of what goes online. Developer notes, with a complete project structure, moved to `docs/development.md`.

## [3.3.0] - 2026-10-28

### Added
- Spoken punctuation in German, English and Polish ("comma", "new line", "question mark" …).
- Shares per language under My languages; short sentences are weighed against the mix.
- A filter for phrases Whisper invents in silence ("Thanks for watching" and similar, ten languages).
- Long dictations on an NVIDIA card decode in parallel batches.

### Changed
- Dark gets its own look; Sage gets drawn icons. Settings and setup are opaque in both designs. The Quicksand font ships with the app.
- Errors name the cause and offer the next step as a button. Closing settings with unsaved changes asks first, and the hotkey field explains why a combination was rejected.

## [3.2.0] - 2026-10-12

### Added
- Agent hotkey (off by default): sends a dictation as JSON to a URL from the settings instead of typing it, with an optional Bearer token, and shows the reply in the overlay. Redirects are not followed. The request format is documented in the README.

## [3.1.0] - 2026-10-10

### Added
- Two designs, Dark and Sage, across every window, or Automatic to follow Windows.
- Line, a calm overlay style that exists in both designs.

## [3.0.0] - 2026-10-09

There is no `v3.0.0` tag in the repository; the version was bumped and followed by 3.1.0 the same day.

### Added
- Copies and screenshots made while dictating into an AI app, a terminal, a code editor or a browser go along with the sentence.
- <kbd>Esc</kbd> cancels a dictation.
- Optional: mute other audio while dictating.

### Changed
- The microphone is remembered by name instead of by index.
- Shortcuts in settings and setup are drawn as key caps.

## [2.9.0] - 2026-10-04

### Added
- One-click updates from GitHub releases for the installed version, with a switch to turn the automatic check off. The portable version links to the release page.

### Changed
- Uninstalling also removes the update cache.

## [2.8.0] - 2026-10-04

### Added
- Start with Windows toggle in settings, tray menu and setup.
- Slime, Dragon and Mimic overlay styles.

### Changed
- Downloaded speech models load from the local cache without asking the Hugging Face Hub.
- The log no longer holds dictated text; older logs that did are deleted once.
- The uninstaller removes `%APPDATA%\NoType` and the autostart entry.

## [2.7.0] - 2026-09-29

### Added
- Command mode: rewrite the selection (or write new text) by voice with the local LLM.
- Learned dictionary of corrections, with suggestions when a dictated word is fixed in place (UI Automation, never in password fields).
- Dot Matrix, Island, Halo and Buddy overlay styles, seven accent colors, live preview in settings.
- In-app update of the portable Ollama.

### Changed
- License changed to MIT with the Commons Clause.
- README rewritten for end users.

## [2.6.0] - 2026-09-05

### Added
- Overlay position (bottom, top, center) for every style; the overlay holds the inserted sentence for a moment.
- Model picker for AI cleanup.

### Fixed
- cuBLAS is bundled with the backend, so the GPU path no longer depends on a CUDA toolkit on `PATH`. The installer grows to about 1 GB.

## [2.5.0] - 2026-09-05

### Added
- Model cards with download size, VRAM need and a recommendation for the detected GPU.
- First-run setup guide with a test dictation.
- A processing state in the overlay after the key is released.

## [2.4.0] - 2026-09-05

### Changed
- Hold-to-speak stops on the real key release instead of a timer, which removes about 350 ms per dictation.
- Toasts follow the app language; settings polish.

### Fixed
- Settings were not saved while the backend was down or restarting.
